# Design Pattern Tracker

A 14-day study tracker for 32 topics: design patterns, resilience, distributed systems and rollout strategies.

- **Tracker:** open [`index.html`](index.html) in a browser. Progress is saved in your browser.
- **Notes:** [`notes/`](notes/README.md) – one easy-language note per topic with Java Spring Boot code. Each topic card in the tracker has a **Notes** button that opens its note.
